# Glosario

| Término | Significado |
|---|---|
| **Algoritmo** | Secuencia ordenada de pasos para resolver un problema |
| **Argumento** | Valor que se entrega a una función al llamarla |
| **Asignación** | Guardar un valor en una variable con `=` |
| **Booleano (`bool`)** | Tipo de dato con solo dos valores: `True` y `False` |
| **Bucle / ciclo** | Estructura que repite instrucciones (`for`, `while`) |
| **Cadena (`str`)** | Secuencia de caracteres; es decir, un texto |
| **Comentario** | Texto que Python ignora, escrito con `#` |
| **Concatenar** | Unir textos, por ejemplo con `+` |
| **Condicional** | Estructura que decide qué ejecutar según una condición (`if`) |
| **Consola / terminal** | Ventana donde se escriben comandos y se ven los resultados |
| **Depurar (debug)** | Buscar y corregir errores en un programa |
| **Diccionario (`dict`)** | Colección de pares clave → valor |
| **Docstring** | Texto entre comillas triples que documenta una función o módulo |
| **Excepción** | Error que ocurre durante la ejecución y detiene el programa si no se controla |
| **f-string** | Texto con prefijo `f` que permite incluir variables entre `{}` |
| **Flotante (`float`)** | Número con decimales |
| **Función** | Bloque de código con nombre que se puede reutilizar |
| **Indentación** | Espacios al inicio de una línea que marcan un bloque de código |
| **Índice** | Posición de un elemento en una secuencia (empieza en 0) |
| **Intérprete** | Programa que lee y ejecuta tu código Python |
| **Iterar** | Recorrer los elementos de una colección uno por uno |
| **JSON** | Formato de texto para guardar datos estructurados |
| **Lista (`list`)** | Colección ordenada y modificable de elementos |
| **Método** | Función que pertenece a un tipo de dato, como `texto.upper()` |
| **Módulo** | Archivo `.py` con código que se puede importar |
| **Parámetro** | Variable que aparece en la definición de una función |
| **Repositorio** | Carpeta de proyecto controlada por Git |
| **Retorno (`return`)** | Valor que una función entrega al terminar |
| **Slicing / rebanado** | Extraer una parte de una secuencia: `texto[1:4]` |
| **Sintaxis** | Reglas de escritura de un lenguaje de programación |
| **Tupla** | Colección ordenada que no se puede modificar |
| **Variable** | Nombre que apunta a un dato guardado en memoria |
| **Commit** | "Foto" guardada del estado del proyecto en Git |
| **Push / Pull** | Subir cambios a GitHub / traer cambios desde GitHub |

# Recursos para seguir aprendiendo

## Documentación oficial

- **Tutorial oficial de Python (en español):** <https://docs.python.org/es/3/tutorial/>
- **Referencia de la biblioteca estándar:** <https://docs.python.org/es/3/library/>

## Herramientas de práctica

- **Python Tutor** (visualiza paso a paso cómo se ejecuta tu código): <https://pythontutor.com/>
- **Terminal interactiva:** escribe `python` (o `python3`) en la terminal para probar instrucciones sueltas. Se sale con `exit()`.

## Git y GitHub

- *Pro Git* en español: <https://git-scm.com/book/es/v2>
- Documentación de GitHub: <https://docs.github.com/es>

## Qué estudiar después de este tutorial

| Tema | Para qué sirve |
|---|---|
| Programación orientada a objetos (clases) | Modelar cosas del mundo real en código |
| Módulos propios y paquetes | Organizar proyectos grandes |
| `csv` y `pandas` | Analizar datos y hojas de cálculo |
| `requests` | Consumir información de internet (APIs) |
| `pytest` | Escribir pruebas automáticas |
| `tkinter` / `streamlit` | Crear interfaces gráficas o aplicaciones web sencillas |
| Flask / Django | Desarrollo web |

## Hábitos que te harán mejorar más rápido

1. **Programa todos los días**, aunque sean 20 minutos.
2. **Escribe el código tú misma**; copiar y pegar no enseña.
3. **Rompe el código a propósito** para ver qué errores aparecen.
4. **Construye proyectos pequeños** que te interesen (un conversor, un juego, un control de gastos).
5. **Lee código de otras personas** y explícate qué hace cada línea.

# Ejercicios de repaso e integración

Cada capítulo (`01_fundamentos`, `02_entrada_salida`, …) ya incluye su propio `ejercicios.md` y `soluciones.py`. Esta carpeta es distinta: reúne **actividades que combinan varios temas** para comprobar que realmente dominas lo aprendido.

## Contenido

| Archivo / carpeta | Descripción | Temas que practica |
|---|---|---|
| `ejercicios_practicos.py` | Calculadora y dos ejercicios guiados | Entrada, condicionales, listas, ciclos |
| `retos_integradores.md` | 7 retos de dificultad creciente | Todo el tutorial |
| `soluciones/` | Una solución por reto (`reto_01_...py`) | — |

## Cómo trabajar

1. Lee el enunciado del reto en `retos_integradores.md`.
2. Planifica en papel: **¿qué datos entran? ¿qué pasos hay? ¿qué resultado sale?**
3. Escribe tu solución en un archivo nuevo, por ejemplo `mi_reto_01.py`.
4. Pruébala con varios valores, incluidos los "raros" (cero, negativos, texto vacío).
5. Solo entonces compara con la solución de la carpeta `soluciones/`.

> 💡 Si te bloqueas, divide el problema en pasos pequeños y resuelve uno por uno. Es exactamente lo que hacen los programadores profesionales.

## Rúbrica de autoevaluación

Marca cada punto cuando tu programa lo cumpla:

- [ ] Hace lo que pide el enunciado.
- [ ] No se detiene con un error si el usuario escribe algo inesperado.
- [ ] Usa nombres de variables claros.
- [ ] Tiene comentarios donde el código no es obvio.
- [ ] Usa funciones cuando una tarea se repite.
